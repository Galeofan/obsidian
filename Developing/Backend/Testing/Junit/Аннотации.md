### @TestInstance

Аннотация управляет **жизненным циклом экземпляра тестового класса**.

```java
import org.junit.jupiter.api.TestInstance;

@TestInstance(TestInstance.Lifecycle.PER_CLASS)
class MyTest {
    ...
}

```

Она отвечает на вопрос:

> **Создаётся ли новый объект тестового класса для каждого теста  
> или используется один и тот же экземпляр?**

PER_CLASS и PER_METHOD
По умолчанию PER_METHOD
