### Навигация
Esc - выход из боковых панелей, фокус обратно на редактор
Alt+Left/Right - перемещение между вкладками
Ctrl+F4 - закрыть вкладку/панель
Ctrl+Shift+F4 - закрыть все вкладки
Ctrl+Tab - открыть меню переключения switcher между файлами и панелями
Ctrl+B или Ctrl+ЛКМ или F4 - с помощью любой из этих команд можно перейти к выбранному классу или методу, то есть показывает источник кода
Ctrl+Alt+B - показать все имплементации метода
Alt+F7 - показывает где используется в проекте выбранный класс, метод и т.д.
Ctrl+E - недавние открытые вкладки
F12 - вернуться на последнюю открытую панель
Ctrl+F12 - показать структуру класса
Ctrl+Shift+F12 - закрыть все панели
Ctrl+G - перейти на строку
Ctrl+N - найти и открыть класс
Ctrl+Shift+N - найти и открыть файл
### База
Ctrl+D - дублировать строку
Ctrl+Y - удалить строку целиком
Ctrl+W - extend selection
Ctrl+Shift+W - shrink selection
F11 - добавить в избранное
### Поиск
Ctrl+F - открывает меню поиска по текущей вкладке
Ctrl+R - меню поиска и замены строки
Ctrl Shift R - замена текста во всем проекте
Ctrl+Shift+F - поиск по проекту
Shift+Shift - поиск везде(кроме методов)
### Классы и методы
Ctrl+Alt+T - обернуть блок кода в базовую конструкцию языка if, try, for, while и т.д.
Alt+Enter - подсказка для решения подсвеченных проблем
Ctrl+Shift+Spacebar - умная автоподстановка
Ctrl+Alt+B - просмотр всех имплементаций
Alt+Insert - генерация классов-тестов + методов-аксессоров
Ctrl+Shift+- - Свернуть все методы
Ctrl+Shift++ - Развернуть все методы
### Рефакторинг
Shift+F6 - изменение имени класса/метода/переменной во всем проекте
Ctrl+Alt+V - создание переменной из результата работы метода 
Ctrl+Alt+M - выносит выделенный кусок кода в отдельный метод
Ctrl+Alt+L - переформатирует код в соответствии с требованиями, указанными в текущей схеме стиля кода
Ctrl+Alt+O - удаляет неиспользуемые импорты из класса.
### Тесты

### GIT
CTRL+K - commit
CTRL+SHIFT+K - commit and push

### DEBUG
Shift+F9 - запуск программы в режиме отладки (debug)
F8(Step Over) - выполняет текущую строку и переходит на следующую в том же методе. Не заходит внутрь вызова метода.
F7(Step Into	) - заходит внутрь метода, если он вызывается в текущей строке.
Shift+F8(Step Out) - завершает текущий метод и возвращается к месту его вызова.
F9(Resume) - продолжает выполнение до следующего breakpoint’а.

### Рефакторинг
Alt + j - выделить одинаковые слова
Alt + shift - множественный курсор
Ctrl + alt + t - обернуть конструкцию в блок 
Ctrl + w - выделение именно по параметрам в скобках
Ctrl + alt + m - вынести код в отдельный метод
Ctrl + alt + v - вынести код в отдельную переменную
Ctrl + alt + f - вынести локальную переменную в поле
Ctrl + alt + c - вынести локальную переменную в константу класса
Ctrl + alt + p - вынести значение параметра метода наверх в вызывающий метод и задать его как параметр
Ctrl + f6 - удобная настройка сигнатуры метода
Ctrl + r - замена текста в выделенном блоке
