Для Gradle:
В кэше gradle source файл не соответствует байткоду, скорее всего из-за того что есть несколько кэшей для одной либы внутри gradle 
Лечится через invalidate caches в ide или вручную очистить папку caches, например 
C:\java\gradle-7.5\caches\modules-2\files-2.1\ru.mts.multitransfer\multitransfer-api\11.5.0
