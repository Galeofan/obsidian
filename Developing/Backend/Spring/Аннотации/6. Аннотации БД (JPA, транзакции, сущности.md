# Сущности
<font color="#ffff00">@Table</font> - аннотация класса. Задаёт название таблицы. Если не задана то по имени класса
<font color="#ffff00">@Schema</font> - аннотация класса. Задаёт название схемы
<font color="#ffff00">@Entity</font> -  аннотация класса. Говорит Hibernate что данный класс это сущность бд т.е. его экземпляры соответствуют реальной таблице. Объекты ставновятся управляемыми внутри транзакции
<font color="#ffff00">@Id</font> - аннотация поля. Помечает поле первичным ключом
<font color="#ffff00">@GeneratedValue</font> - аннотация поля. Генерация первичного ключа по стратегии(strategy = GenerationType.Sequence)
	<font color="#0070c0">GenerationType.IDENTITY</font> - ID генерируется самой БД как _identity/auto-increment_ колонка. JPA получает значение после `INSERT`
	<font color="#0070c0">GenerationType.SEQUENCE</font> - ID берётся из sequence-объекта БД. Самая «правильная» стратегия для PostgreSQL/Oracle. Требуется sequence в БД и настройка генератора. <font color="#ffff00">@SequenceGenerator</font>(name = "payment_seq", sequenceName = "payment_seq", allocationSize = 50)
	<font color="#0070c0">GenerationType.TABLE</font> - отдельная таблица хранит «последний выданный ID». JPA обновляет её и использует как источник.
	<font color="#0070c0">GenerationType.AUTO</font> - JPA-провайдер (Hibernate и т.п.) выбирает стратегию автоматически в зависимости от диалекта БД и настроек.
<font color="#ffff00">@Column</font> - аннотация поля. Необязательна если не хотим делать поле каким-то особенным, например (unique = true). Все поля внутри Entity по-умолчанию и так column

# JPA
<font color="#ffff00">@OneToMany</font> - 

<font color="#ffff00">@Transient</font> -
**Что делает**
- Исключает поле/свойство из JPA-маппинга.
- Hibernate/JPA **не создаст колонку**, **не будет читать/писать** это поле в таблицу.

**Когда использовать**
- Нужно вычисляемое значение (например, `UUID -> String`) **только для выгрузки/логики**, а не для хранения в БД.
- Нужно поле “для удобства”, которое не должно попадать в схему.

**Важно**
- <font color="#ffff00">@Transient</font> **не мешает** использовать поле в JDBC-выгрузке (NamedParameterJdbcTemplate / batchUpdate), если значение берётся через getter.

**Рекомендуемый стиль (вычисляемое свойство)**
```kotlin
import javax.persistence.Transient

@Entity
class PartnerCatalog {
    @Id
    var id: UUID? = null

    @get:Transient
    val idAsString: String
        get() = requireNotNull(id) { "PartnerCatalog.id is null; cannot export" }.toString()
}
```

# Примеры
```java
package com.example.payhub.persistence;

import jakarta.persistence.*;
import org.hibernate.Hibernate;
import org.hibernate.annotations.BatchSize;

import java.math.BigDecimal;
import java.time.Instant;
import java.util.*;

/**
 * Пример "богатой" Entity для платежного хаба:
 * - Таблица, индексы, уникальные ограничения
 * - ID через SEQUENCE
 * - Optimistic Locking (@Version)
 * - Enum как STRING
 * - Value Object через @Embedded + @AttributeOverride
 * - Большой текст (@Lob)
 * - JSON/Map через @Convert
 * - Аудит createdAt/updatedAt через @PrePersist/@PreUpdate
 * - Связи ManyToOne / OneToMany / ManyToMany
 * - Утилитарные методы для управления двунаправленными связями
 * - @Transient вычисляемое поле
 */
@Entity
@Table(
        name = "payment",
        schema = "payhub",
        uniqueConstraints = {
                @UniqueConstraint(name = "uk_payment_external_id", columnNames = {"external_id"})
        },
        indexes = {
                @Index(name = "ix_payment_status_created_at", columnList = "status, created_at"),
                @Index(name = "ix_payment_payer_id", columnList = "payer_id"),
                @Index(name = "ix_payment_beneficiary_id", columnList = "beneficiary_id")
        }
)
@Access(AccessType.FIELD)
public class PaymentEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "payment_seq")
    @SequenceGenerator(
            name = "payment_seq",
            schema = "payhub",
            sequenceName = "payment_seq",
            allocationSize = 50
    )
    private Long id;

    /**
     * Внешний идентификатор (корреляция с внешними системами/шинами).
     * Обычно это лучший "business key" для интеграций.
     */
    @Column(name = "external_id", nullable = false, updatable = false, length = 36)
    private UUID externalId;

    @Version
    @Column(name = "lock_version", nullable = false)
    private long version;

    @Enumerated(EnumType.STRING)
    @Column(name = "status", nullable = false, length = 32)
    private PaymentStatus status;

    /**
     * В JPA у ManyToOne по умолчанию EAGER — почти всегда это нежелательно.
     * Явно ставим LAZY.
     */
    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "payer_id", nullable = false, foreignKey = @ForeignKey(name = "fk_payment_payer"))
    private PartyEntity payer;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "beneficiary_id", nullable = false, foreignKey = @ForeignKey(name = "fk_payment_beneficiary"))
    private PartyEntity beneficiary;

    /**
     * Value Object (сумма + валюта) как Embedded.
     * AttributeOverride нужен, чтобы назвать колонки в таблице платежей.
     */
    @Embedded
    @AttributeOverrides({
            @AttributeOverride(name = "amount", column = @Column(name = "amount", nullable = false, precision = 19, scale = 4)),
            @AttributeOverride(name = "currency", column = @Column(name = "currency", nullable = false, length = 3))
    })
    private MoneyEmbeddable money;

    /**
     * Большое текстовое поле: примечание/описание/сырой payload.
     * Для PostgreSQL это будет TEXT; для некоторых БД — CLOB.
     */
    @Lob
    @Basic(fetch = FetchType.LAZY)
    @Column(name = "details")
    private String details;

    /**
     * Метаданные/атрибуты (например: channel, userAgent, traceId, flags).
     * Храним как JSON (через AttributeConverter).
     */
    @Convert(converter = StringMapToJsonConverter.class)
    @Column(name = "metadata_json")
    private Map<String, String> metadata = new LinkedHashMap<>();

    /**
     * OneToMany: операции/статусные переходы/аудитные события.
     * orphanRemoval=true гарантирует удаление "сирот" при удалении из коллекции.
     */
    @OneToMany(mappedBy = "payment", cascade = CascadeType.ALL, orphanRemoval = true)
    @OrderBy("createdAt ASC")
    @BatchSize(size = 50)
    private List<PaymentOperationEntity> operations = new ArrayList<>();

    /**
     * ManyToMany: например, лейблы для аналитики/поиска.
     * Чаще всего это либо справочник, либо тегирование.
     */
    @ManyToMany
    @JoinTable(
            name = "payment_label",
            schema = "payhub",
            joinColumns = @JoinColumn(name = "payment_id", foreignKey = @ForeignKey(name = "fk_payment_label_payment")),
            inverseJoinColumns = @JoinColumn(name = "label_id", foreignKey = @ForeignKey(name = "fk_payment_label_label"))
    )
    private Set<LabelEntity> labels = new LinkedHashSet<>();

    @Column(name = "created_at", nullable = false, updatable = false)
    private Instant createdAt;

    @Column(name = "updated_at", nullable = false)
    private Instant updatedAt;

    protected PaymentEntity() {
        // JPA требует конструктор без аргументов (минимум protected).
    }

    private PaymentEntity(UUID externalId, PartyEntity payer, PartyEntity beneficiary, MoneyEmbeddable money) {
        this.externalId = Objects.requireNonNull(externalId, "externalId");
        this.payer = Objects.requireNonNull(payer, "payer");
        this.beneficiary = Objects.requireNonNull(beneficiary, "beneficiary");
        this.money = Objects.requireNonNull(money, "money");
        this.status = PaymentStatus.CREATED;
    }

    public static PaymentEntity newPayment(UUID externalId, PartyEntity payer, PartyEntity beneficiary, MoneyEmbeddable money) {
        return new PaymentEntity(externalId, payer, beneficiary, money);
    }

    @PrePersist
    private void onCreate() {
        Instant now = Instant.now();
        if (externalId == null) {
            externalId = UUID.randomUUID();
        }
        if (status == null) {
            status = PaymentStatus.CREATED;
        }
        createdAt = now;
        updatedAt = now;
    }

    @PreUpdate
    private void onUpdate() {
        updatedAt = Instant.now();
    }

    // -----------------------
    // Доменные методы (важнее сеттеров)
    // -----------------------

    public void addOperation(PaymentOperationEntity operation) {
        Objects.requireNonNull(operation, "operation");
        operation.attachTo(this);
        operations.add(operation);
    }

    public void removeOperation(PaymentOperationEntity operation) {
        if (operation == null) return;
        operations.remove(operation);
        operation.detach();
    }

    public void addLabel(LabelEntity label) {
        if (label == null) return;
        labels.add(label);
    }

    public void removeLabel(LabelEntity label) {
        if (label == null) return;
        labels.remove(label);
    }

    public void markProcessing() {
        ensureCurrentStatus(PaymentStatus.CREATED, PaymentStatus.VALIDATED);
        this.status = PaymentStatus.PROCESSING;
    }

    public void markCompleted() {
        ensureCurrentStatus(PaymentStatus.PROCESSING);
        this.status = PaymentStatus.COMPLETED;
    }

    public void markFailed(String reason) {
        // В реальном коде: записать reason в details/операцию/metadata.
        this.status = PaymentStatus.FAILED;
        if (reason != null && !reason.isBlank()) {
            this.details = reason;
        }
    }

    private void ensureCurrentStatus(PaymentStatus... allowed) {
        for (PaymentStatus s : allowed) {
            if (s == this.status) return;
        }
        throw new IllegalStateException("Invalid status transition from " + status + ", allowed: " + Arrays.toString(allowed));
    }

    // -----------------------
    // Derived / transient
    // -----------------------

    @Transient
    public boolean isHighValue() {
        if (money == null || money.amount == null) return false;
        // пример: "крупный платеж" — бизнес-правило
        return money.amount.compareTo(new BigDecimal("1000000.00")) >= 0;
    }

    // -----------------------
    // Getters (минимальный набор)
    // -----------------------

    public Long getId() { return id; }
    public UUID getExternalId() { return externalId; }
    public PaymentStatus getStatus() { return status; }
    public PartyEntity getPayer() { return payer; }
    public PartyEntity getBeneficiary() { return beneficiary; }
    public MoneyEmbeddable getMoney() { return money; }
    public Map<String, String> getMetadata() { return metadata; }
    public List<PaymentOperationEntity> getOperations() { return Collections.unmodifiableList(operations); }
    public Set<LabelEntity> getLabels() { return Collections.unmodifiableSet(labels); }
    public Instant getCreatedAt() { return createdAt; }
    public Instant getUpdatedAt() { return updatedAt; }

    // -----------------------
    // equals / hashCode (важно для Hibernate)
    // -----------------------

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null) return false;
        if (Hibernate.getClass(this) != Hibernate.getClass(o)) return false;
        PaymentEntity that = (PaymentEntity) o;
        // На практике: если ID уже назначен, сравниваем по нему.
        // Пока ID null (не сохранено) — считаем объекты разными.
        return id != null && Objects.equals(id, that.id);
    }

    @Override
    public int hashCode() {
        // Рекомендация Hibernate: hashCode не должен меняться после persist.
        // Используем "классовый" hashCode пока id не задан.
        return (id == null) ? Hibernate.getClass(this).hashCode() : id.hashCode();
    }

    // -----------------------
    // Supporting types (обычно в отдельных файлах)
    // -----------------------

    public enum PaymentStatus {
        CREATED,
        VALIDATED,
        PROCESSING,
        COMPLETED,
        FAILED
    }

    @Embeddable
    public static class MoneyEmbeddable {

        @Column(name = "amount", precision = 19, scale = 4)
        private BigDecimal amount;

        @Column(name = "currency", length = 3)
        private String currency;

        protected MoneyEmbeddable() {}

        public MoneyEmbeddable(BigDecimal amount, String currency) {
            this.amount = Objects.requireNonNull(amount, "amount");
            this.currency = Objects.requireNonNull(currency, "currency");
        }

        public BigDecimal getAmount() { return amount; }
        public String getCurrency() { return currency; }
    }
}

/**
 * Пример дочерней сущности для OneToMany.
 * Обратите внимание на attach/detach, чтобы держать связь консистентной.
 */
@Entity
@Table(name = "payment_operation", schema = "payhub",
        indexes = {@Index(name = "ix_payment_operation_payment_id", columnList = "payment_id")}
)
class PaymentOperationEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "payment_id", nullable = false, foreignKey = @ForeignKey(name = "fk_operation_payment"))
    private PaymentEntity payment;

    @Column(name = "operation_type", nullable = false, length = 64)
    private String operationType;

    @Column(name = "created_at", nullable = false, updatable = false)
    private Instant createdAt;

    protected PaymentOperationEntity() {}

    public PaymentOperationEntity(String operationType) {
        this.operationType = Objects.requireNonNull(operationType, "operationType");
    }

    @PrePersist
    private void onCreate() {
        createdAt = Instant.now();
    }

    void attachTo(PaymentEntity payment) {
        this.payment = Objects.requireNonNull(payment, "payment");
    }

    void detach() {
        this.payment = null;
    }

    public Instant getCreatedAt() { return createdAt; }
}
```
