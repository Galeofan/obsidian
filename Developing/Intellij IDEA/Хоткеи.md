### Навигация по проекту и файлам
Esc — вернуть фокус в редактор  
Alt+Left / Alt+Right — переход между последними открытыми вкладками  
Ctrl+Tab — меню переключения между файлами и панелями  
Ctrl+E — список недавно открытых файлов  
F12 — вернуться на предыдущую панель  
Ctrl+F12 — структура файла  
Ctrl+G — перейти к строке  
Ctrl+N — открыть класс  
Ctrl+Shift+N — открыть файл  
Shift+Shift — глобальный поиск (везде)  
Ctrl+Shift+A — поиск действия/команды  
Ctrl+B / Ctrl+ЛКМ / F4 — перейти к объявлению  
Ctrl+Alt+B — перейти к имплементациям  
Alt+F7 — показать все usages  
Ctrl+U — перейти к родительскому методу/классу  
Ctrl+Alt+Home — перейти к навигационному бару  
Ctrl+Shift+T — перейти к тесту / создать тест

### Управление вкладками и окнами
Ctrl+F4 — закрыть вкладку  
Ctrl+Shift+F4 — закрыть все вкладки  
Ctrl+Shift+F12 — скрыть/показать все панели  
Ctrl+Shift+E — последние изменённые файлы  
Alt+1 — открыть/закрыть Project View  
Alt+7 — открыть/закрыть Structure

### Редактирование текста
Ctrl+D — дублировать строку  
Ctrl+Y — удалить строку  
Ctrl+W — расширить выделение  
Ctrl+Shift+W — сузить выделение  
Alt+J — выделение следующих совпадений  
Alt+Shift — множественные курсоры  
Ctrl+/ — закомментировать строку  
Ctrl+Shift+/ — блок комментарий  
Ctrl+Shift+↑ / ↓ — перемещение строки  
Ctrl+Backspace — удалить слово слева  
Ctrl+Delete — удалить слово справа  
F11 — добавить в избранное  
Ctrl+Shift+V — буфер подстановки (история копирования)

### Поиск и замена
Ctrl+F — поиск в текущем файле  
Ctrl+R — замена в текущем файле  
Ctrl+Shift+F — поиск по проекту  
Ctrl+Shift+R — замена по проекту  
Ctrl+Alt+F7 — показать usages всплывающим окном  
Ctrl+Shift+F7 — подсветить все совпадения в файле

### Работа с кодом и конструкциями
Ctrl+Alt+T — обернуть в конструкцию (if/try/for/while…)  
Alt+Enter — контекстные подсказки (quick fix)  
Ctrl+Shift+Space — умная автоподстановка  
Alt+Insert — генерация кода (конструкторы, геттеры, тесты и т.п.)  
Ctrl+Shift+- — свернуть всё  
Ctrl+Shift++ — развернуть всё  
Ctrl+Q — быстрая документация  
Ctrl+P — подсказка параметров метода  
Ctrl+O — переопределить методы  
Ctrl+I — реализовать интерфейс

### Рефакторинг
Shift+F6 — переименование  
Ctrl+Alt+M — вынести код в метод  
Ctrl+Alt+V — вынести выражение в переменную  
Ctrl+Alt+F — вынести в поле  
Ctrl+Alt+C — вынести в константу  
Ctrl+Alt+P — параметризовать значение (протянуть в вызывающий метод)  
Ctrl+Alt+Shift+T — меню рефакторинга  
Ctrl+F6 — изменение сигнатуры метода  
Ctrl+Alt+O — оптимизация импортов  
Ctrl+Alt+L — автоформатирование кода  
F6 — переместить файл/класc  
F5 — копировать файл/класс  
Alt+Delete — безопасное удаление с анализом usages  
Shift+F6 — rename во всех контекстах

### Работа с GIT
Ctrl+K — commit  
Ctrl+Shift+K — push  
Alt+` — меню VCS  
Ctrl+Shift+A → "changelist" — управление change-группами  
Ctrl+D в diff — перейти к следующему изменению  
Ctrl+Shift+D — сравнить с предыдущей версией из history

### Debug
Shift+F9 — запуск в debug  
F8 — Step Over  
F7 — Step Into  
Shift+F8 — Step Out  
F9 — Resume  
Alt+F9 — выполнить до курсора  
Ctrl+F8 — поставить/снять breakpoint  
Ctrl+Shift+F8 — управление breakpoint’ами  
Ctrl+Alt+F8 — вычисление выражения (Evaluate)

### Запуск и сборка
Shift+F10 — запуск  
Ctrl+Shift+F10 — запуск текущего файла/класса  
Ctrl+F9 — сборка проекта  
Ctrl+Shift+F9 — сборка выбранного модуля  
Ctrl+Alt+S — настройки IDEA  
Ctrl+Alt+Shift+S — настройки проекта/модулей (Project Structure)

### Полезные хоткеи, которые часто используют сеньоры
Alt+Insert — создание класса
Ctrl+Shift+Enter — завершить строку умно (добавит ;, закроет скобки)  
Ctrl+Shift+J — склейка строки (join lines)  
Shift+Ctrl+Alt+J — выделить все вхождения  
Ctrl+Shift+Alt+L — выбор настроек форматирования перед применением  
Ctrl+Shift+Alt+N — поиск по символам (метод, поле)  
Ctrl+Shift+Alt+S — Project Structure  
Alt+Shift+Mouse Wheel — масштаб редактора  
Ctrl+Shift+U — смена регистра  
Ctrl+Alt+Shift+I — инспекции на выделенном участке
