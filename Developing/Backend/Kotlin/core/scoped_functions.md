# ✔ 1. `let` — _преобразовать значение_

Используем, когда нужно **взять объект и вернуть из блока что-то другое**.
Идеально для безопасного использования nullable.
### Сигнатура:
`T?.let { it: T -> R } : R?`
### Пример:
`val date = (value as? String)?.let(LocalDate::parse)`
### Когда использовать:
- преобразование (`map-подобное`)
- работа с nullable значениями
- ограничение области видимости переменной

# ✔ 2. `also` — _выполнить действие, не изменяя объект_

Типичный use-case — логирование, побочные эффекты.
### Сигнатура:
`T.also { it: T -> Unit } : T`
### Пример:
`val user = loadUser().also {     logger.info("Loaded user ${it.id}") }`
### Когда использовать:
- логирование
- дебаг
- запись в кэш
- побочные действия _без изменения цепочки_

---
# ✔ 3. `apply` — _настроить объект_
Используется для конфигурации объекта при создании.
### Сигнатура:
`T.apply { this: T -> Unit } : T`
### Пример:
`val person = Person().apply {     name = "John"     age = 30 }`
### Когда использовать:
- строитель объектов
- конфигурация DTO / UI / builders

---
# ✔ 4. `run` — _выполнить блок и вернуть результат_
Комбинация `let` + `apply`.
### Сигнатура:
`T.run { this: T -> R } : R`
### Пример:
`val length = "hello".run {     println(this)     this.length }`
### Когда использовать:
- когда нужен результат, а не сам объект
- избежать временных переменных

---
# ✔ 5. `with` — _как run, но не вызывается на объекте_
### Сигнатура:
`with(obj) { this: obj -> R }`
### Пример:
`val result = with(person) {     "$firstName $lastName" }`
### Когда использовать:
- когда нужно вызвать много методов одного объекта
- объект не nullable
