## div
**`<div>`** — блочный _контейнер общего назначения_.
- Сам по себе **ничего не значит семантически** (в отличие от `<header>`, `<nav>`, `<main>`).
- Используется для **группировки** элементов, чтобы:
    - применить CSS (фон, отступы, сетку),
    - управлять расположением (flex/grid),
    - повесить обработчики событий в JS.
**Поведение по умолчанию:** блочный элемент → занимает всю ширину строки и начинается с новой строки.

## span
**`<span>`** — строчный _контейнер общего назначения_.
- Тоже **без семантики**.
- Используется для выделения части текста/встроенного контента для стилей или JS.
**Поведение по умолчанию:** строчный элемент → не переносит строку, занимает ширину по содержимому.

## input
**`<input>`** — элемент **ввода данных** в формах.
Это “универсальный” контрол, который меняется через атрибут `type`:
- `type="text"` — текст
- `type="password"` — пароль
- `type="email"` — email
- `type="number"` — число
- `type="date"` — дата
- `type="checkbox"` — чекбокс
- `type="radio"` — радио-кнопка
- `type="file"` — файл
- `type="submit"` — кнопка отправки
