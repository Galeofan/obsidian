# Маршрутизация

<font color="#ffff00">@RequestMapping</font> – Ставится на классе и на методах. Базовая аннотация Spring MVC, которая **связывает HTTP-запрос (путь + метод + доп. условия) с обработчиком**: контроллером или конкретным методом. 

---
<font color="#ffff00">@GetMapping</font> – помечает метод контроллера Spring MVC как обработчик **HTTP GET** запроса по указанному пути.
Часто используется с:
- <font color="#ffff00">@PathVariable</font> (часть пути):
```java
@GetMapping("/api/users/{id}") 
UserDto getUser(@PathVariable long id) { ... }
```
- <font color="#ffff00">@RequestParam</font> (query-параметр):
```java
@GetMapping("/api/users") 
List<UserDto> find(@RequestParam String q) { ... }
```
