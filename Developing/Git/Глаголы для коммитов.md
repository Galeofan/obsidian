### Добавление нового

- **add** — добавить функциональность/фичу/эндпоинт/параметр
    - `add phone number validation`
    - `add transfer status mapping`
### Удаление
- **remove** — удалить код/функцию/файл/опцию
    - `remove deprecated sbp adapter`
- **drop** — удалить поддержку/фичу (часто про функциональность, более “жёстко”)
    - `drop legacy schema support`

### Изменение существующего поведения
- **change** — изменить логику/поведение (сильнее чем update)
    - `change rounding rules for commission`
- **adjust** / **tweak** — небольшая корректировка
    - `adjust retry timeout`
- **fix** — исправить баг (должно быть багфикс, а не “просто правки”)
    - `fix null handling for recipient document`

### Рефакторинг (без изменения поведения)

- **refactor** — переработать структуру кода без изменения внешнего поведения
    - `refactor JsonSchemaFlattener to stream-based traversal`
- **simplify** — упростить код
- **cleanup** — чистка/удаление мусора/мертвого кода
- **rename** — переименовать (классы/методы/поля)
- **extract** — выделить (метод/класс)
    - `extract phone parser into PhoneNumberNormalizer`

### Документация и инфраструктура
- **test** / **add tests** — добавить/обновить тесты
- **docs** — документация
- **build** — сборка/зависимости/Gradle
- **ci** — пайплайны
- **chore** — “прочее” (форматирование, мелкие правки, не влияющие на продукт)
