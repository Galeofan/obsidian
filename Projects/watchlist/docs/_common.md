# Общее описание
## 1. Цель проекта
Создать сервис для учёта просмотренного медиа-контента (фильмы, сериалы), позволяющий пользователю фиксировать просмотры, просматривать историю, фильтровать данные и получать базовую аналитику. Проект служит учебной платформой для освоения полного цикла разработки: frontend (React + TypeScript), backend (Spring Boot 3.4), PostgreSQL, Docker и архитектурных практик.

---
## 2. Основные функции
### MVP
- Добавление элемента просмотренного контента:
    - название
    - год выпуска
    - тип (MOVIE / SERIES)
    - дата просмотра
    - рейтинг от 1 до 10
    - комментарий
    - автоматическая дата создания
- Просмотр списка всего контента
- Фильтрация по типу контента
- Сортировка по всем полям
- Удаление элемента
### Пост-MVP (Backlog)
- Авторизация JWT
- Теги, жанры, заметки
- Продвинутая статистика
- Пагинация
- Импорт из внешних сервисов (Кинопоиск, IMDb, YouTube)
- Рекомендации
- UI улучшения, адаптация под мобильные
- Экспорт/импорт данных

---
## 3. Ограничения
### Технические
- MVP без авторизации (фиксированный userId)
- REST API без WebSocket/GraphQL
- Минимальный UI — только рабочий функционал
- Хранение в PostgreSQL, миграции Flyway
### Продуктовые
- Главная цель — получить рабочую версию как можно быстрее
- Упрощённая модель данных
- На MVP — только три типа контента
